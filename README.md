# AI in Radiotherapy — Interactive Workshop

A Streamlit teaching prototype for a Master 2 workshop covering:
1. Image registration
2. Organ-at-risk segmentation
3. Dose prediction

## Run locally

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```

## Publish online with Streamlit Community Cloud

1. Create a GitHub repository.
2. Upload `app.py` and `requirements.txt` to the repository root.
3. Open https://share.streamlit.io/ and sign in with GitHub.
4. Choose **Create app**, select the repository and `app.py`.
5. Deploy. Streamlit will provide a public URL to share with students.

## Important scientific limitation

This is an educational prototype. Registration uses a known synthetic translation; segmentation uses shifted synthetic masks; the dose-like field is generated by a simplified mathematical function. None of these is a trained AI model, a validated registration algorithm, a clinical segmentation tool, or a clinical dose calculation. Replace the teaching examples with anonymized/public images and validated model outputs before presenting them as research results. Do not upload identifiable patient data to a public application.
